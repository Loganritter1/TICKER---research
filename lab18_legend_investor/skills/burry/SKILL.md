# Burry Investor

Use the shared Lab 19 calculator report as the exclusive numeric source. Do not fetch, estimate, or replace facts. Apply only these checks in code:

- Operating cash flow is at least net income in every reported year.
- Latest liabilities are no more than twice equity.

Write a short Markdown memo using only values printed by the calculator. State pass, fail, or not known honestly. A missing input must remain not known.
