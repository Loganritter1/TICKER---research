# Lab 18 — Legend Investor as Skill

Run the script (replace the User-Agent with your own name and email):

```powershell
.venv\Scripts\python.exe lab18_legend_investor\edgar_buffett.py COST --user-agent "Your Name your.email@school.edu" --json-out lab18_legend_investor\cost.json
```

Run the app:

```powershell
.venv\Scripts\python.exe -m streamlit run lab18_legend_investor\app.py
```

Use the `legend-investor` skill after installing its folder under `C:\Users\logan\.codex\skills\legend-investor`.
